# Group 03 - Worksheet Solutions Dashboard

## 1. Project Description

This project presents a Streamlit-based dashboard that combines the Python solutions for Questions 1–4 of the Computational Mathematics worksheet. It provides a user-friendly interface for selecting and executing individual solutions.

The application displays the results and available graphs, making it easier to explore each solution in one place. By integrating the existing Python modules, the dashboard avoids duplicating mathematical computations and maintains a modular project structure.

## 2. Technologies Used

- Python
- Streamlit
- Matplotlib
- Pandas
- Git and GitHub

## 3. Project Files

- `app.py` - Main interactive dashboard
- `Q1.py` - Question 1 solution
- `act4_q2.py` - Question 2 solution
- `Q3.py` - Question 3 solution
- `Q4.py` - Question 4 solution
- `student_performance.csv` - Dataset used in the project

## 4. Setup Instructions

1. Install Python on your computer.
2. Clone or download the project repository from GitHub.
3. Open Command Prompt or a terminal in the project folder.
4. Install the required Python packages:

```bash
python -m pip install streamlit matplotlib pandas
```

Install any additional packages required by the individual question scripts.

## 5. Execution Steps

1. Open Command Prompt in the project folder.
2. Run the following command:

```bash
python -m streamlit run app.py
```

3. Open the local URL displayed in the terminal.
4. Select a question from the dashboard.
5. Click the **Run Selected Question** button.
6. View the output and graphs, where available.
