
# Computational Mathematics — Week 04 Dashboard

An interactive dashboard for the AM 3038/3084 Computational Mathematical Modeling activity.

## Features

- Question 1: Descriptive statistics and histogram
- Question 2: Matrix calculations, eigenvalues, and linear systems
- Question 3: Polynomial equations, derivatives, and integration
- Question 4: Student performance analysis and interactive charts

## Requirements

Python 3.10 or newer is recommended.

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

## Run the dashboard

```bash
python -m streamlit run app.py
```

## Student data

Upload `student_performance.csv` in Question 4 to explore the student performance data.
